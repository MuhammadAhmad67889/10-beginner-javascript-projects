# 10 Beginner JavaScript Projects

**Try them live:** https://muhammadahmad67889.github.io/10-beginner-javascript-projects/

Ten small projects I built to learn JavaScript properly — one concept at a time.
No frameworks, no build step, no API keys. Every project runs on its own:
just open its `index.html` in a browser.

## The projects

| # | Project | What you practise |
|---|---------|-------------------|
| 01 | [Counter](./01-counter) | DOM updates, event listeners, state |
| 02 | [Todo List](./02-todo-list) | Arrays, event delegation, localStorage |
| 03 | [Calculator](./03-calculator) | State machines, string-to-number handling |
| 04 | [Stopwatch](./04-stopwatch) | Timers, time formatting |
| 05 | [Random Quote Generator](./05-random-quote-generator) | Arrays, random picks, clipboard |
| 06 | [Color Flipper](./06-color-flipper) | Random values, inline styles |
| 07 | [Tip Calculator](./07-tip-calculator) | Live input handling, money maths |
| 08 | [Password Generator](./08-password-generator) | Strings, randomness, form controls |
| 09 | [Rock Paper Scissors](./09-rock-paper-scissors) | Game logic, score keeping |
| 10 | [Quiz App](./10-quiz-app) | Rendering from data, progress, scoring |

## How to run

No install needed. Open any project's `index.html` in your browser, or serve
the whole folder if you prefer (for example with the VS Code Live Server
extension) so every project works from one place.

## Notes

- Each folder is self-contained: its own HTML, CSS and JS, so you can copy
  a single project out and it still works.
- The code is deliberately plain. Where there was a choice between a clever
  shortcut and a readable one, I took the readable one.
